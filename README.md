# newcomer-kids-korean

중도입국 초등학생을 위한 한국어 읽기 진단과 학습 앱입니다.

- `index.html` : 첫 화면
- `diagnosis/` : 한국어 읽기 진단 1·2단계 (주소 끝에 `#teacher`를 붙이면 선생님 화면)
- `img/` : 그림 (진단과 학습이 함께 사용)
- `Code.gs` : 결과를 구글 시트에 저장하는 Apps Script (시트에 붙여 넣어 배포)


## 2차 진단 (diagnosis2/)
- 1차에서 어휘·문장이 각각 80점(5개 중 4개) 이상인 아이만 풀어요. 1차 마지막 화면에 링크가 나와요.
- 영역: 교과 어휘 · 긴 문장 · 문단 읽기 · 교과서 지시문 (각 5문항, 4개 이상이면 통과)
- 결과는 같은 구글 시트의 '2차 결과', '2차 문항별 답' 탭에 쌓여요.
